# Décathlon — Rencontre amicale d'athlétisme

Site de suivi en direct d'une rencontre amicale d'athlétisme organisée à Pantin.

Les participants et spectateurs peuvent consulter depuis leur téléphone :
- le programme et les infos de chaque épreuve ;
- les classements par épreuve et le classement général ;
- le profil de chaque participant avec ses résultats.

## Fonctionnement

- Site statique (HTML / CSS / JavaScript), hébergé sur GitHub Pages.
- Les résultats sont saisis par les organisateurs dans un Google Sheet.
- Le site lit ce Google Sheet et calcule les classements automatiquement.

## Lancer le site en local

Ouvrir `index.html` dans un navigateur.
